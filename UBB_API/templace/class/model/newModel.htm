创建模板

  • 第一步：登录【电脑管理后台】，地址：http://你的域名/admin/login.aspx
  • 第二步：左边导航栏【网站管理】→点击【页面模板管理】
  • 第三步：左上角【模板名称管理】→输入页面名称→输入顺序号，随便写个数字就行，一般0
  • 第四步：模板创建成功后，点击【返回】→点击我们刚才创建的模板

创建页面源码

  • 第一步：左上角【新增页面源码】
  • 第二步：输入页面名称
  • 第三步：输入页面源码
  • 第四步：根据自己的需要，配置相关使用条件后保存即可。具体可以查下面的详解。↓↓↓↓

版本配置

只能选择一个版本
  • ver=0：自动识别，所有ver均可使用。
  • ver=1：wap1.0简版已经淘汰，配置该属性，此页面只能ver1使用。
  • ver=2：html5触屏版，当ver=2的时候是一
  • ver=3：电脑版，当ver=3的时候使用
  • ver=4：自定义拓展版本1，当ver=4的时候使用
  • ver=5：自定义拓展版本2，当ver=5的时候使用

优先级顺序：
如当前页面有ver0和ver2两个页面，ver2会被优先使用。1,2,3,4,5,都优先级都比0高

页面位置

  • 顶部：默认网站顶部使用
  • 底部： 默认网站底部使用
  • 普通栏目：需要配置指定栏目id使用
  • 指定栏目顶部：需要配置指定栏目id使用
  • 指定栏目底部：需要配置指定栏目id使用
  • 指定栏目中部 ：需要配置指定栏目id使用

系统会优先使用指定栏目的

指定栏目id

此页面模板只能在该栏目id下面使用，多个使用,隔开，栏目下级格式用栏目ID+*,例:128*,栏目128下下级用128**,以此类推，多组用,区分，例：128*,158**。
