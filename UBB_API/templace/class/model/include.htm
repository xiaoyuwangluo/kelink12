页面嵌套

格式：[include]页面名称[/include]，该UBB只能在本页面模板中调用
  • 第一步：创建一个页面模板
  • 第二步：创建一个页面源码，名称叫【自定义页面】，输入内容：我就是你的页面内容
  • 第三步：在其他页面调用方法：[include]自定义页面[/include]，UBB将输出：我就是你的页面内容

取页面标签内容

格式：[include=标签名称]页面名称[/include]
  • 第一步：创建一个页面模板
  • 第二步：创建一个页面源码，名称叫【自定义页面】，输入内容：[标签一]我就是标签的内容[/标签一]
  • 第三步：在其他页面调用方法：[include=标签一]自定义页面[/include]，UBB将输出：我就是标签的内容

传参和内部变量值

格式：[include=标签名称_参数1_参数2_参数3_....依次递增]页面名称[/include]
  • 第一步：创建一个页面模板
  • 第二步：创建一个页面源码，名称叫【自定义页面】，输入内容：[标签一]我就是标签的内容，tid={tid}，参数1={t1}，参数2={t2}，......[/标签一]
  • 第三步：在其他页面调用方法：[include=标签一_参数1_参数2]自定义页面[/include]，UBB将输出：我就是标签的内容，tid=45454，参数1=参数一，参数2=参数二，......

封装万能UBB案例

  • 第一步：创建一个页面模板
  • 第二步：创建一个页面源码，名称叫【自定义UBB】，复制下面内容↓↓↓↓
[布局一] 
      <!--tid={tid};layout={t0}; start-->
      <ul id="kl-{tid}">
        [{t1}={t2}_{t3}_{t4}_{t5}_100*
        <li><a href="{linkurl}">{title} </a></li>
        /{t1}]
      </ul>
      <!--tid={tid};layout={t0}; end--> 
[/布局一]

调用方法：[include=布局一_功能模块_N_M_X_Y]自定义UBB[/include]
如：[include=布局一_bbs_0_6_1_12]自定义UBB[/include]
