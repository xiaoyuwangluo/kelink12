常见问题

1.万能ubb调用的时候，部分模块报错？

因为万能ubb涉及到很多模块的调用，所以有的模块发生错误无法调用是很正常的，可以将此BUG反馈给我们，我们会在第一时间修复。

2.万能ubb如何实现多层嵌套？

万能ubb每次调用的时候，都会执行一次正则替换，把[,/,{这三个符合后面的#去掉一个，如果去掉#之后，生成新的万能ubb，程序将会继续解析。例子： 

    [class=0_99_9_12_100*  <!--第一级循环，取栏目信息-->
    	<h2><a href="{linkurl}">{classname}</a></h2>
        <ul>
        	[#bbs={classid}_6_1_12_100*   <!--第二级循环，取到栏目ID{classid}后再循环取对应的论坛帖子标题和链接，如有第三级用##，以此类推-->
            	<li><a href="{#linkurl}">{#title}</a></li>
            /#bbs]
        </ul>
    /class]
