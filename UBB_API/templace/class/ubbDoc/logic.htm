基本逻辑判断

UBB 说明
[logins]登录后内容[/logins] 登录后显示内容
[nologins]未登录内容[/nologins] 未登录显示内容
[show=X_Y]条件成立显示内容[/show] 指定条件下显示的内容
X：可以是指定模块（如：bbs），指定路径（如：/bbs/list.aspx），指定栏目id（如：0）
Y：0时表示所有网站,1时VIP网站,2时非VIP网站
PS：多个条件使用 | 隔开 ,首页固定标识default，所有类型网站只首页显示内容:[show=default_0]内容[/show]
[noshow=X_Y]条件不成立显示内容[/noshow] 指定条件下不显示的内容
X：可以是指定模块（如：bbs），指定路径（如：/bbs/list.aspx），指定栏目id（如：0）
Y：0时表示所有网站,1时VIP网站,2时非VIP网站
PS：多个条件使用 | 隔开,首页固定标识default，所有类型网站除了首页显示内容:[noshow=default_0]内容[/noshow]
[wap=X]指定版本显示内容[/wap] 指定版本显示内容
X：为0,1,2,3,4...
PS：1为简版，2为触屏版，3为电脑版，其他属于自定义拓展
[mobi]手机可见内容[/mobi] 指定版本显示内容
[coin=金钱数]输入内容[/coin] 指定版本显示内容 金钱可见内容
[grade=等级]输入内容[/grade] 等级可见内容
[vip=身份级别ID多个用|区分]输入内容[/vip] 身份级别可见内容
[switch=X]
{case=1}
X=1显示我
{case=3}
X=2显示我
......可以自行添加更多条件
{default}
上面的条件都不成立，就显示我
[/switch]		 X,可以是UBB，基于不同的条件来显示不同的内容
