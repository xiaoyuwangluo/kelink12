功能类

UBB 说明
[url=URL地址]链接标题[/url] 文本链接
[imgurl=320*200]图片地址*链接地址[/imgurl] 图片链接
[float=图长*图宽*离左边距离*离顶部距离*X]图片地址*链接地址[/float] 浮动图片链接
X：0时左边，1时右边显示
[img]图片URL地址[/img] 显示图片
[img=图片URL地址]说明[/img] 显示图片2，注意：图片后缀为gif|jpg|bmp|jpeg|png其它只能首页显示。
[js]地址[/js] 调用js文件
[css]地址[/css] 调用css文件
[iframe=320*200]链接地址[/iframe] 插入iframe框架
[anchor=广告地址]广告标题[/anchor] 无下划线链接
[rndurl=地址1|地址2]说明或图片地址1|说明或图片地址2[/rndurl] 随机图文链接
[rndtxt]说明或图片地址1|说明或图片地址2[/rndtxt] 随机图文显示，多个用|或｜区分开，支持文字或图片混合链接
[picurl8=320*200]图片地址1|图片地址2*链接地址1|链接地址2[/picurl8] 带数字滚动图片(=布局8)
[picurl9=320*200]图片地址1|图片地址2*链接地址1|链接地址2[/picurl9] 从右向左平滑滚动图片(=布局9)
[picurl10=320*200]图片地址1|图片地址2*链接地址1|链接地址2[/picurl10] 带点滑滚动图片(=布局10)
[movie=320*180]视频地址|图片地址[/movie] 视频播放
[audio=X]音频地址[/audio] 音频播放
X：0时不自动播放，1为自动播放,2自动并循环播放
[map]320*240[/map] 手机定位地图(HTML5)
[map=纬度*经度]320*240[/map] 纬度经度定位地图(HTML5)，例:[map=23.02978910711622*113.30886358323664]320*240[/map]
[ul=myclass]智能判断分行[/ul] UI标签，列表使用li标签
[call]手机号码[/call] 直接拨号
[call=号码]说明[/call] 带说明的直接拨号
[url=sms:手机号码?body=短信内容]点击此发送[/url] 发短信到手机
[tq=X]默认地区的区号[/tq] 天气预报
X：0时样式0，X=1时样式1，X=2时样式2
