[getwml=标题ID] WAP1.0/2.0如何插入WML或XHTML代码？请先建栏目指向html5功能模块，
在添加删除内容中添加html5代码，然后用[getwml=标题ID]调用或直接转成UBB语法，建议使用页面模板！
[readhtm]html文件路径，直接读取以html，htm后缀的文件[/readhtm] 此UBB无缓存功能，建议用【页面模板管理】有缓存
[getform]标题ID[/getform] 如何插入表单提交？请先建栏目指向表单设计模块，在添加删除内容中设计好表单，然后用[getform]标题ID[/getform]调用
[showhtml]html代码[/showhtml] 将html代码以字符串的形式输出， 该UBB只能在论坛帖子内容和回复中使用
