使用方法

UBB 说明
[ui]X[/ui] 获取当前会员信息，如获取当前会员的昵称：[ui]1[/ui]
X：可以选择上面的数字，调用出对应的信息
[ui=X]HTML[/ui] 获取当前会员信息，如获取当前会员的昵称：[ui]1[/ui]
X：调用出指定id的会员信息，多个使用 | 隔开
HTML：这里可以可以使用html和会员内部变量混编
[users=N_M_X_Y_Z] 调用会员数据，此ubb不支持使用内部变量：
N：为0时随机,1最新，针对X=0,1时有效
M：为返回条数，最多20条；
X：为0时，所有会员活动记录；为7时在线会员活动记录；为1时注册会员在线活动记录；为2时最新注册会员；为3时最新注册男会员，为4时最新注册女会员； 为5时财富榜排行；为6时经验排行榜。(注意，当X>=3时，统计可能会慢，尽量少用)
Y：为0时换行，为1时不换行。
[user=N_M_X_Y_100*HTML，可调用会员内部变量/user] 调取指定身份的会员：
N：取会员身份id，0为所有身份，如果取普通会员身份可以使用0|0
M：返回条数
X：0为最新20条中随机，1为最新，2空间点击量，3金币，4经验，5为随机所有，6发帖量，7回贴量，8是推荐，9最新上线会员，10登录次数
Y：参数1*参数2*参数3，参数1是昵称长度，参数2是签名长度，参数3为1时为在线
